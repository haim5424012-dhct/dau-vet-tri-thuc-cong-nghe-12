# Checklist — Xác minh bundle mới và cache GitHub Pages

- [ ] Kiểm tra HTML, JavaScript bundle và URL production hiện tại.
- [ ] Tìm chuỗi “Frontend không phải két sắt” trong artifact/bundle đang phục vụ.
- [ ] Nếu còn bundle cũ, triển khai lại hoặc tạo cache-busting URL.
- [ ] Kiểm tra trực tiếp URL mới và xác nhận checklist 3 bước hiển thị.
- [ ] Bàn giao link mới, kèm hướng dẫn tải lại nếu trình duyệt còn cache.
