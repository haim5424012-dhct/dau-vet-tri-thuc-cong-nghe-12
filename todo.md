# Checklist — Sửa lỗi URL fragment GitHub Pages

- [ ] Kiểm tra App Router và các liên kết hash trong Home.
- [ ] Bổ sung xử lí fragment để mọi hash quay về Home và cuộn đúng section.
- [ ] Chạy check/test/build và đẩy commit mới lên GitHub.
- [ ] Chờ GitHub Actions deploy thành công.
- [ ] Kiểm tra URL gốc và URL có `#kiem-chung`, `#rubric`, `#gui-bai`.
- [ ] Bàn giao link dùng cho học sinh.
